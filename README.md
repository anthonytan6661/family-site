## 🌟 核心战略与三大住宿大本营 (Master Route & 3 Strategic Hubs)

针对家庭亲子出行痛点，全行程采取“落地直奔高山 + 下吕平日温泉修整 + 名古屋7晚连住长住大本营”结构，彻底告别频繁收拾行李搬家：

1. **阶段一 · 飞驒高山腹地 (4晚, 11/26 - 11/30)**：
   * **首日直奔高山**：08:30 落地后不进名古屋市区，直接乘名铁 μ-SKY (09:36) 衔接 JR 特急飞驒7号 (10:48 HC85新型车全景窗)，车上吃便当午休，13:13 抵达高山出站步行2分钟即达酒店。
   * **住宿基地**：**高山车站公寓式酒店 (Residence Hotel Takayama Station)**（4独立单床、房内独立洗烘机、配备完整厨房）。
   * **辐射游玩**：三町老街、宫川朝市、味藏天国A5飞驒牛顶奢烧肉、白川乡合掌村、飞驒古川《你的名字》圣地巡礼。
2. **阶段二 · 下吕名汤平日修整 (1晚, 11/30 - 12/01)**：
   * **周一平日特惠**：高山乘特急仅43分钟直达下吕。**周一入住避开周末人流峰值，立省约 10,000 日元**。
   * **住宿基地**：**下吕温泉 水明馆 (Gero Suimeikan)**（纯正日式榻榻米大客房、三大温泉浴场、包含4人奢华飞驒牛会席晚宴及朝食自助）。
3. **阶段三 · 名古屋都会连住大本营 (7晚, 12/01 - 12/08)**：
   * **整整7天零搬家**：下吕特急1小时35分直达名古屋，入住大须套房后整整一周不再收拾打包行李，免除黑猫跨城行李转运费（净省4,800円）。
   * **住宿基地**：**GOLD STAY 名古屋大须 (GOLD STAY Nagoya Osu)**（4床套房、房内独立日立洗烘一体机、连住7晚周长住特惠）。
   * **辐射游玩**：
     * **12/03 (周四) 吉卜力公园**：工作日错峰入园，排队减少50%，拍照体验极佳。
     * Toyota产业技术纪念馆、国宝犬山城下町、名古屋城金鯱横丁、热田神宫。
     * 行程末尾集中在大须商业街与荣商圈扫货二次元中古手办、玩具与伴手礼。
   * **D13 返程**：06:45 退房 ➔ 07:20 μ-SKY 直达中部机场T1 ➔ Flight of Dreams 波音787乐园 ➔ 10:20 SQ671 直飞回新。
